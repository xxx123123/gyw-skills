# 岗位清闲度标注

把“单一职能、没有那么多交叉事务的单位更清闲”这类经验，转成可复用、可解释的岗位评分方法。核心不是给单位贴“闲/忙”标签，而是按可操作的五变量给**具体职位**打分。

## 何时使用

- 用户给出一份公务员/事业单位/省考/国考职位表（xls/xlsx/csv/md），要求判断“哪些岗位不累/清闲/适合躺平”。
- 用户提到“人防办式单位”“单一职能单位”“冷门清闲单位”，想在其他岗位表里找类似特征。
- 需要给岗位清单补充一列“清闲度”或输出优先级排序。

## 核心判断公式

> **远离中心工作 × 低问责风险 × 编制充足 × 财政供养稳定 × 岗位不在核心业务科**

“专职某一单独领域”只是帮你避开“上面千条线、下面一根针”，它是**必要条件，不是充分条件**。不要直接把“单位冷门”等同于“岗位清闲”。

两个必须反复强调的修正：

1. **单位闲 ≠ 你闲**。忙单位有闲岗，闲单位有忙岗。具体科室是办公室、综合科、财务、人事、执法、窗口，一律降档。
2. **你的技能是单位主业 → 你反而忙**。例如数据局、大数据局、网信办里，计算机岗是主力；科技局、统计局、医保、财政里，计算机岗是辅助，反而更接近“事少”。

## 评分标准

对每个**职位**打 `高 / 中 / 低`，并在必要时备注原因。

- **高（相对最接近“人防办式”）**
  - 单一职能、非核心部门、离两办/组织部/纪委远；
  - 无执法、无审批窗口、无夜班/值班、无一票否决或高频问责；
  - 你的岗位是技术/辅助角色，不是单位核心业务；
  - 全额拨款或垂管，财政稳定。
- **中**
  - 无执法/值班，但属于核心或指标部门（发改、财政、工信、商务等），或 IT 是主业（数据局），或有一定窗口/材料压力；
  - 忙闲取决于科室与时间节点。
- **低（明确忙且易背锅）**
  - 执法、监管、应急、纪检、审计、信访、公安、法院执行、城管；
  - 两办、组织部、宣传部核心岗；
  - 乡镇/街道等基层；
  - 明确写“需经常出差/夜间值班/周末值班/加班值守/驻点办案”的，直接低。

> 口径统一：评的是“单位职能 + 岗位角色 + 问责风险”，不是保证。忙闲最终还取决于科室、领导、地区财政。

## 单位速查表

**相对清闲（但通常招人少、专业限制多）**
档案局/馆、地方志办/史志办、党史研究室、老干部局、供销社、气象局、地震局、科协/文联/社科联/侨联/残联/工商联（群团）、党校、人大/政协机关、红十字会、机关事务管理局、住房公积金中心、外事办/台办/民族宗教、粮食和物资储备（垂管）。

**忙 / 背锅（避免默认“清闲”）**
两办、组织部、纪委监委、应急管理局、公安局、市场监管局、生态环境局、信访局、城管、发改委核心科室、财政局预算/国库核心岗、税务窗口、乡镇街道、法院执行、住建审批/拆迁。

**中性（看科室）**
科技局、工信局、数据局、统计局、医保局、民政局、人社局、文体广旅局、商务局。

**特别提醒：人防办已经变了。** 2022 年底起各地以原人防办为基础组建“国防动员办公室”，职能从单一防空扩展为综合国防动员，需协调发改、工信、交通、科技等部门，基层还常一人多岗。**不要再拿“人防办清闲”当模板**；人防工程科历来最忙。

## 操作流程

1. **拿到原始职位表**，不要只依赖二手职位库。
   - `.xls` 旧格式用 `xlrd`：`xlrd.open_workbook(path, encoding_override='gbk')`；先导出 UTF-8-SIG 的 CSV 再处理，避免控制台乱码。
   - 提取字段：隶属关系、地区、单位名称、职位名称、职位简介、考试类别、招考人数、学历、专业、其他条件（备注）。
2. **逐职位判定**：命中速查表 + 看职位简介里的动词（“执法/监管/值班/出差/办案/信访/审批/窗口” → 降档；“信息化/数据/技术保障/系统维护” → 看是否为主业）。
3. **标注到 Markdown**：在表末追加“清闲度”列。可用 `scripts/add_rating_column.py` + 一份 JSON 映射批量完成。
4. **补图例与优先名单**：在表格前加评分说明，并单列“清闲度=高，优先看”的代码。
5. **输出免责声明**：明确“没有真正的清闲单位，只有相对最优”，并提示机构改革、借调、招录少、晋升慢等代价。

## 输出模板

```markdown
## 清闲度标注说明

评的是「单位职能是否单一、是否非核心、有无执法／值班／问责、以及本岗位是主力还是辅助」。

- **高**：单一职能、非核心、无执法无值班，岗位为辅助，最接近“人防办式”节奏。
- **中**：无执法／值班，但属核心或指标部门，或技术岗是主业，忙闲取决于科室与节点。
- **低**：执法、监管、应急、纪检、审计、乡镇街道等，明确忙且容易背锅。

> 提醒：清单里没有真正的“人防办型”单位，标注的“高”只是相对最优。

**清闲度=高，优先看：** 单位A `代码`、单位B `代码`。

| 地区 | 招录单位与职位 | 代码 | 类别 | 人数 | 学历 | 专业 | 工作内容与附加条件 | 清闲度 |
|---|---|---|---|:---:|---:|---|---|---|:---:|
| ... | ... | `...` | A | 1 | 研究生 | ... | ... | 高 |
```

## 常见坑

- **不要给绝对承诺**：同一单位不同科室差异巨大；新人常被分到最忙的科室。
- **清闲的代价**：晋升慢、交流少、职数少、成就感低、人员老化。
- **招录频率**：真正清闲的单位往往长期不招人，多等退休补录；岗位专业/学历限制高。
- **借调/抽调**：清闲单位的人常被抽去巡察、创城、扶贫、专班。
- **改革撤并**：粮食局并入发改委、人防办改国动办、事业单位分类改革。
- **编制性质**：行政编 / 参公 / 全额事业 / 差额 / 自收自支，待遇与稳定性不同。
- **地区与层级**：基层一人多岗；省市更规范但核心部门更忙。

## 配套脚本

`scripts/add_rating_column.py` 给任意 Markdown 表追加评分列：

```bash
python scripts/add_rating_column.py positions.md ratings.json \
  --column 清闲度 --code-header 代码 --default —
```

`ratings.json` 形如 `{"050000/010/03": "低", "050000/067/01": "中"}`。脚本会找到表头中含“代码”的列，用反引号内的代码去匹配，并在表末追加评分列；已存在同名列的表会跳过。
