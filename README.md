# gyw-skills

个人整理的 Agent Skills 合集，主要用来解决自己备考和工作中反复遇到、又缺少现成工具的问题。

## 背景

计算机科学与技术专业，工作多年，中年，正在准备考公／考编上岸。

真正开始选岗后才发现，考公最难的不是刷题，而是**信息不对称**：

- 职位表只写单位、专业、学历和一句“从事……工作”，看不出这个岗位到底累不累；
- 网上“十大清闲单位”的盘点大多是过时经验，例如人防办早已在 2022 年后陆续改为国防动员办公室，职能扩展、协调量变大，不再是当年那个样本；
- “单位清闲”不等于“你清闲”：忙单位有闲岗，闲单位有忙岗，新人还常被分到最忙的科室；
- 对计算机专业的人来说，还要额外判断一件事：**信息化到底是这个单位的主业，还是辅助？** 是主业（如数据局），你多半是主力；是辅助（如科技局、统计局），反而更接近“事少”。

与其每次凭感觉，不如把判断口径固定下来，让 AI 拿到一份职位表就能按同一套标准逐岗标注。这就是 `gongkao-post-chill-rating` 的由来。

## Skills

### `gongkao-post-chill-rating`

为公务员／事业单位／省考／国考职位表标注「清闲度」，并追加“清闲度”列、图例和优先名单。

核心判断公式：

> 远离中心工作 × 低问责风险 × 编制充足 × 财政供养稳定 × 岗位不在核心业务科

评分口径：

- **高**：单一职能、非核心、无执法／值班／一票否决，本岗位是技术或辅助角色；
- **中**：无执法值班，但属核心或指标部门，或技术岗就是主业，忙闲看科室和节点；
- **低**：执法、监管、应急、纪检、审计、信访、乡镇街道等，明确忙且容易背锅。

同时内置单位速查表、常见坑（借调、改革撤并、编制性质、招录频率）和免责说明。

批量标注脚本：

```bash
python skills/gongkao-post-chill-rating/scripts/add_rating_column.py positions.md ratings.json \
  --column 清闲度 --code-header 代码 --default —
```

`ratings.json` 形如：

```json
{
  "050000/010/03": "低",
  "050000/067/01": "中",
  "050700/005/01": "高"
}
```

## 说明

- 内容为个人经验整理，**非官方口径**，不构成报考建议；
- 忙闲因地区、层级、科室、领导而异，标注只做相对参考；
- 欢迎交流指正，但请以官方职位表、招录简章和专业目录为准。
